### 💊 MedSync
Plataforma criada para **ajudar pessoas que esquecem de tomar seus medicamentos**, organizando horários e lembretes de forma simples.

| Parte | Descrição | Stack |
|---|---|---|
| 🎨 **[MedSync Frontend](https://github.com/luansxz-fee/front)** | Interface web do projeto, responsiva e fácil de usar. | `React` `TypeScript` |
